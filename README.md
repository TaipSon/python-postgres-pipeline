Python & Data Pipeline + AI Agent: Интерактивная аналитика инженерных данных

Собственная разработка конвейера данных (Data Pipeline) для автоматического извлечения данных из проектирования зданий и создания интерактивного ИИ-помощника. Проект решает реальную задачу: автоматизирует расчет объемов и сметной стоимости материалов, а также позволяет общаться с данными на человеческом языке через локального ИИ-агента.

🛠 Стек технологий

• Язык программирования: Python (Pandas, sys, io, json)
• Инструменты извлечения (Сбор данных): Autodesk Revit / Dynamo
• База данных / СУБД: PostgreSQL, DBeaver
• Интеграция ИИ (Agentic AI): Локальная LLM через Ollama (Qwen2.5:3b) на базе видеокарты RTX 3070
• BI-аналитика: Yandex DataLens (визуализация метрик)

🏗 Архитектура пайплайна (Как это работает)

1. Extraction (Извлечение): Из модели выгружаются сырые данные по элементам конструкций (геометрия и объёмы материалов). Данные экспортируются в формат CSV.
2. Transformation & Business Logic (Обработка данных):
	• Скрипт на Python с использованием Pandas считывает файл, очищает строки от суффиксов единиц измерения (м³) и приводит их к числовому типу float. <br>
	• Применяется бизнес-логика: автоматически рассчитывается стоимость каждой стены на основе марки бетона (В25, В30 и др.) и формируются сводные аналитические датафреймы. <br>
3. Agentic AI (Интерактивный ИИ-Аналитик):
	• В коде развернут бесконечный цикл диалога с локальной нейросетью Qwen. <br>
	• Главная фишка: Модель изолирована от самостоятельных расчетов (чтобы исключить галлюцинации). Когда пользователь спрашивает «Сколько бетона нужно?» или «Какая итоговая стоимость?», ИИ-агент сам пишет точный Python-код, выполняет его в изолированной песочнице через exec() и выдает пользователю абсолютно точный математический ответ человеческим языком.<br>

📊 Результаты и ценность проекта

• Полностью исключен человеческий фактор и ошибки при подсчете объемов материалов и стоимости.
• Создан удобный интерфейс: вместо написания сложных SQL-запросов или формул, любой сотрудник может узнать точные цифры по проекту, просто задав вопрос роботу в консоли.

## 🗄️ Верификация данных и SQL-аналитика (`sql_queries_library.sql`)

Для ручной верификации данных, тестирования заложенной бизнес-логики и развертывания расчетных витрин на уровне СУБД разработан автономный инженерный сборник скриптов. Он интегрирован в репозиторий в виде структурированной библиотеки запросов **`sql_queries_library.sql`**.

Сборник разбит на функциональные слои и решает следующие задачи в рамках проекта:

* **Инспекция сырых логов (DQL):** Оперативный контроль качества данных, импортированных из CSV-дампов Revit, направленная выборка и формирование бизнес-алиасов для отчетов.
* **Управление DWH и контроль целостности (DDL/DML):** Инициализация таблиц базы данных PostgreSQL, конфигурация ограничений и проверка системы защиты от дублирования записей через первичные ключи (`PRIMARY KEY`).
* **Агрегация и группировка (Aggregation):** Сбор статистики и подсчет точного количества конструктивных элементов (стен), сгруппированных по их маркам.
* **Слой ETL-трансформации (Views):** Проектирование расчетных представлений для очистки текстовых параметров BIM-модели «на лету» (удаление мусорных маркеров `м³`, замена разделителей и приведение к точному числовому типу `NUMERIC`).
* **Аудит метаданных:** Мониторинг актуальной структуры таблиц и схем данных через прямое обращение к системным каталогам PostgreSQL.
